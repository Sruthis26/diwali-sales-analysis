# Diwali Sales Analysis

## Overview
This project focuses on analysing Diwali sales data to understand customer purchasing behaviour and identify patterns in sales across different customer segments and product categories.

Using Python, the dataset is explored to discover trends related to customer demographics, geographical locations, occupations, and product preferences.

## Objectives
- Understand customer purchasing behaviour.
- Analyse sales across different gender and age groups.
- Identify the top-performing states.
- Explore purchasing patterns based on marital status and occupation.
- Identify the highest-performing product categories.
- Find products with the highest order quantities.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Data Analysis Process

### 1. Data Loading
Imported the sales dataset into Python using Pandas.

### 2. Data Cleaning
- Removed unnecessary columns.
- Identified and handled missing values.
- Converted the sales amount column into an integer data type.
- Checked the structure and consistency of the dataset.

### 3. Exploratory Data Analysis
Performed analysis across multiple categories:
- Gender
- Age Group
- State
- Marital Status
- Occupation
- Product Category
- Product ID

### 4. Data Visualization
Created visualisations using Matplotlib and Seaborn to identify trends and compare sales performance across different customer segments.

## Key Insights
- Female customers contributed more to total recorded sales than male customers.
- The 26–35 age group recorded the highest total spending.
- Uttar Pradesh, Maharashtra, and Karnataka were the leading states in total sales.
- Customers working in IT, Healthcare, and Aviation contributed significantly to sales.
- Food was the highest-performing product category by total sales amount.

## Business Recommendations
- Focus on understanding the purchasing preferences of the 26–35 age group.
- Explore targeted promotional campaigns in high-performing states.
- Use product category trends to improve inventory planning.
- Develop customer-segment-based marketing strategies.

## Project Structure

- `Diwali_Sales_Analysis.ipynb` – Python notebook containing data cleaning, analysis, and visualisations.
- `Diwali Sales Data.csv` – Dataset used for the analysis.

## Conclusion
The analysis provides insights into customer demographics, purchasing patterns, and product performance during Diwali sales. These findings can help businesses better understand customer preferences and make informed decisions regarding marketing and inventory planning.
